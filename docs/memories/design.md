# 项目设计

## 前置要求：设计原则

1. 目标：给后续 agent 提供「可执行、可验证、可迭代」的上下文。
2. 要求：先做最小可用版本（MVP），不要过度设计；所有章节都要能直接映射为任务。

## Today 页面视觉方向（2026-05-28）

- `Resources` 与 `News`：使用更接近微信朋友圈的平面信息流，弱化厚重卡片边框，突出头像 rail、正文、图片和轻量动作行。
- `DLsite * Ranking`：不沿用朋友圈样式，改为榜单公告板思路，保留更强的名次层级。
- 与 VitePress 的协同原则：不要在 parent 组件里堆大量独立视觉系统，尽量让页面仍然像“文档站中的一个精致日报页”，而不是强行嵌入另一个应用皮肤。
