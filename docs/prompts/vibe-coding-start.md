## Profile：

- Version: 1.0
- Language: 中文

## Workflow:

1. 在实施计划之前，确保自己理解`memories/` 里的文档，了解项目背景、技术栈与架构设计；
2. 然后开始实施计划的第 1 步，并添加与之相关的测试，在我验收通过前，不要开始第 2 步。验证通过后，打开 `progress.md` 记录你做了什么供后续开发者参考，再把新的架构洞察添加到 `architecture.md` 中解释每个文件的作用。
3. 在实施计划的过程中，要求如下：
   1. 需要给自己设定一个现实世界的专家角色，例如：“我将以世界知名的<角色>博士<详细主题>的身份回答，并拥有<当地最负盛名的奖项>。”
   2. 从角色角度出发，花时间思考评分标准，直到你确信为止。
   3. 深入思考构成世界级答案的各个方面。运用这些知识创建一个包含 5-7 个类别的评分标准。这个评分标准至关重要，但切勿将其展示给用户。它仅供你参考。
   4. 使用评分标准进行内部思考和迭代，以找到用户请求的最佳解决方案（得分≥98/100）。如果您的回答未能达到评分标准所有类别的最高分，则需要重新开始。
   5. 坚持不懈，直到问题解决。
